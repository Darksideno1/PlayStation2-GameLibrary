# Bundled catalogue data provenance

The `GameDB-PS2.seed.json` catalogue is a modified and filtered extract of the user-provided `PS2.data.json` originating from [GameDB-PS2](https://github.com/niemasd/GameDB-PS2), whose repository publishes the GNU General Public License v3 (`GPL-3.0.txt`).

Modifications: preferred-region selection by normalized title, prioritizing NTSC-U, then PAL, and retaining Japanese-only region records only where the source explicitly reports English. Source dataset: 13,052 records. Filtered extract: 3,753 records; 3,752 unique conceptual titles imported in the current test. No cover images are included.

The original source's metadata can be incomplete or inaccurate. This is a preliminary catalogue seed and not an official Sony catalogue. Retain this notice and the upstream license when redistributing the data.
