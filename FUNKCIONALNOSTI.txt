PLAYSTATION 2 GAME LIBRARY v0.1 BETA — DEVELOPMENT STATUS
Last updated: 2026-10-16
Current baseline: approved HTML v11 design is being transferred into the existing WPF/.NET 8 application without replacing the SQLite data layer.

LOCKED PRODUCT DIRECTION
- Windows desktop application: WPF / .NET 8.
- English user interface.
- Light blue-gray design with left navigation, central list/content area and right details panel.
- Separate USER and ADMIN builds.
- Existing SQLite catalogue/collection data layer retained.
- USER collection types: Physical and Digital only. Older OPL rows remain non-destructively compatible in the schema/database but are not part of the current USER workflow.
- Media rule: ONE GAME = ONE FRONT COVER.
- Front covers are local files, not downloaded automatically from the web.
- Supported cover formats: JPG, JPEG, PNG and WebP.
- Media Library root is configurable and may be relative, local, external-disk or NAS based.

IMPLEMENTED IN CURRENT FEATURE BRANCH
- Rebuilt WPF Catalog shell based on the approved v11 HTML prototype.
- Catalog search plus Region, Language and Release Type filters.
- Region and language values displayed with graphical flag images.
- Catalog ownership status for Physical/Digital collection copies.
- Right-side selected-game panel with large proportional front cover and neutral missing-cover placeholder.
- Local cover lookup by the conceptual game's selected primary serial from <Media Library>\Covers.
- Front-cover display preserves aspect ratio; original cover files are never modified.
- Game Details window with one large front cover and explicit Regions & Releases mapping (region + serial + language flags).
- My Collection limited to Physical and Digital in current USER workflow, with multiple copies of one game, digital sizes, notes and persistent SQLite storage.
- Per-copy Physical inventory: Original case, Cover, Disc and Manual presence plus independent condition values.
- Digital file format plus purchase/source metadata.
- Dashboard WPF screen with Games with cover, Games without cover, coverage ring, missing-cover list and Total Digital Size.
- Settings WPF screen with Media Library Location, Browse, Test Path, Open Covers Folder and thumbnail-cache preference.
- Import / Export WPF screen with complete SQLite backup, validated restore with automatic safety backup, collection JSON/CSV export, import preview and duplicate skipping.
- Searchable Help WPF screen covering Quick Start, Catalog, My Collection, Front Covers, Backup & Restore, Troubleshooting and About.
- C# GameDB-PS2 catalogue import preview/apply service remains available in ADMIN build.
- Separate USER and ADMIN portable builds remain supported.

MEDIA / COVER BEHAVIOUR
- Cover filename is based on the conceptual game's primary serial, e.g. SLES-52541.jpg.
- Linked PAL / NTSC-U/C / NTSC-J releases share the same conceptual-game front cover.
- No country/language-specific cover variants are managed.
- Missing or unreachable Media Library paths do not invalidate catalogue data; the UI falls back to No cover available.
- Dashboard coverage is derived from locally present cover files.
