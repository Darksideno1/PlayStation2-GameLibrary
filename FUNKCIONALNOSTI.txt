PLAYSTATION 2 GAME LIBRARY v0.1 BETA — DEVELOPMENT STATUS
Last updated: 2026-10-15
Current baseline: Windows CI-verified development baseline; portable release artifact is built by GitHub Actions after every successful main-branch build.

IMPLEMENTED IN SOURCE
- WPF main-window catalogue shell with search, region filter, catalogue grid and navigation.
- WPF App.xaml startup declaration and shared UI resources.
- SQLite schema for conceptual games, regional releases, discs, languages, source provenance, import history, review queue and collection entities.
- Python reference importer with preview/apply, explicit approval gate, transaction, source snapshots and idempotence tests.
- C# JSON import service connected to the Import catalogue button, with preview summary, row-level preview export, explicit confirmation and transactional apply path.
- My Collection with independent Physical, Digital and OPL copies, multiple copies of the same game, digital sizes, notes, filters and totals.
- Per-copy physical inventory: edition, cover/case/disc/manual presence and independent component condition.
- Per-copy Digital/OPL metadata: file format, OPL version, compatibility and VMC status.
- Optional per-copy purchase date, price and seller.
- Saved per-copy inventory/OPL details are shown directly in the My Collection right-side panel when a row is selected; the separate details window remains the editor.
- SQLite backup/restore with validation, overwrite confirmation and pre-restore safety backup.
- Separate USER and ADMIN portable builds.

VERIFIED BY WINDOWS CI / AUTOMATED SMOKE TESTS
- Starter catalogue creation and persistence in SQLite.
- Catalogue -> Add to Collection -> My Collection GUI flow.
- Collection insert and persistence after database reopen.
- Two distinct copies of the same game are retained independently.
- Detailed physical inventory persists after database reopen.
- Windows portable USER and ADMIN build/package pipeline.

DATA / IMPORT VERIFICATION
- Actual local PS2.data.json previously inspected: 13,052 keyed records; 8,514 non-empty release_date values; observed formats YYYY (399), YYYY-MM (49), YYYY-MM-DD (8,066), and 4,538 empty/null values.
- Python importer unit tests and idempotence checks are retained in the test suite.
- Bundled starter catalogue uses preferred-region selection rules and is only seeded when the local catalogue is empty.

MY COLLECTION — CURRENT STATUS
- Physical / Digital / OPL: implemented.
- Multiple copies of the same game: implemented and smoke-tested.
- Physical cover, case, disc and manual presence/condition: implemented and persisted per copy.
- Digital size in GB: implemented with live total storage calculation.
- OPL version, compatibility and VMC status: implemented per copy.
- Add, edit, delete and persistent SQLite save/reopen: implemented.
- Selected-copy details without an extra click: implemented; saved inventory/OPL information appears in the right panel.
- Detailed inventory / OPL settings editor remains available for changing those values.
